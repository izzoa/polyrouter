## Design Specificity Verdict

LLM assessment: half-authored. The color, elevation and responsive rules are rigorous and specific to polyrouter. The component layer is category-generic. "The Switchboard" generates the brand mark and the One Live Signal Rule, but no component. The signature is a KPI tile. Polyrouter's real signature has no anatomy: the route a request took (agent, layer, attempts, served model, first-token commit) and its price receipt. Line 208 says "only one signal is lit at a time", but line 227 lists 7 concurrent indigo uses.

## Overall Impression

The foundations are excellent: split status tokens, Dark-Is-Flat, literal breakpoints. But DESIGN.md is a careful record of what's built, not a plan for what should be built (line 212). The biggest opportunity is to make it lead: give "Numbers never lie" and "The Switchboard" real components, and fix the contrast debt in the tokens.

## What's Working

- Split status tokens. Fills (2.7–3.9:1) never carry text. The -text variants measure 4.84–6.57:1.
- The Machine-String Rule suits a router.
- Rules that state their own failure mode: Literal Breakpoint, Class-Not-Inline and Dark-Is-Flat.

## Priority Issues

### [P1] Tokens build in WCAG 2.2 AA failures

Measured contrast:

| Pair | Ratio | Required |
|---|---|---|
| Dark link and ghost-hover text | 3.70 | 4.5 |
| Dark primary hover (white on #6c83ff) | 3.32 | 4.5 |
| Input edge | 1.13 | 3 |
| Input fill | 1.04 | 3 |
| Selected segment | 1.13 | 3 |
| Active-nav wash | 1.07 | 3 |
| Faint glyphs | 2.03 | 3 |

Fix:
- Add `accent-text` (light #414fc7, dark #6c83ff).
- Add `accent-fill-hover`, #414fc7 in both themes.
- Add `border-control` (light #8e9097, dark #62646d, about 3.05:1).
- Use one selected treatment everywhere: Indigo Wash, Deep Ink label at 500, and a 2px accent inset bar.
- Draw meaningful glyphs in Ink 3, not Faint.

Command: /impeccable audit

### [P1] "Numbers never lie" has no visual vocabulary

Add a Figure States section, one treatment per state:

| State | Treatment |
|---|---|
| Exact | Ink, tabular |
| Estimated | `est.` tag, never amber |
| Below precision | `<$0.01` |
| Unpriced | the word, never $0.00 |
| Pending | `—`, and nothing else uses the dash |
| Loading | figure-width skeleton |
| Failed | Retry, plus "routing is unaffected" |
| Stale | "as of hh:mm · stale" in amber-text |
| Reserved | `≤ $x` |
| Over | "over by $x" in red-text |
| Paused | full-contrast phrase; opacity is for disabled controls only |

Command: /impeccable harden

### [P1] The Switchboard never becomes a component

Add:
- A Route Trace: source, layer chip, then attempt nodes. The served path is a 2px accent stroke. Failed attempts are red-text nodes; skipped ones are dashed Ink 3 "not contacted". Add a commit marker.
- A Price Receipt block.

Make the inspector 560px wide and non-modal at 1280px and wider, with up and down arrows stepping between rows. This needs an OpenSpec change.

Command: /impeccable shape

### [P2] No control geometry, so rows misalign by design

The specimen measured control heights of 18, 19, 25, 27, 30, 32 and 34px, with tops 8.5px apart. Primary and cancel share padding yet differ by 2px (the border).

Fix:
- Control heights: 24px small, 32px default, 44px for coarse pointers.
- Give primary a transparent 1px border.
- Centre the toggle.
- Radii down to 4 values: 4, 6, 10, 16.
- Type down to 5 sizes: 11, 12, 13, 15, 26.

Command: /impeccable layout

### [P2] The system contradicts itself

- Set an indigo budget: one solid fill per view, with toggles-on moving to an Ink track.
- Amber Delete collides with amber caution. Use red-text ghost plus a red commit (#b42318, 6.57:1). This needs a dashboard-core spec change.
- Dashed lines carry two meanings.
- Chip-tone group rows contradict the Hairline Rule.
- Line 375's motion claim is wrong.

Fix with a per-control state matrix.

Command: /impeccable polish
